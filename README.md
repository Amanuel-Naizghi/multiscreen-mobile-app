# Indeed Mobile Application

A multi-screen mobile application developed with **Expo, React Native, and TypeScript**, inspired by the Indeed job-search application.

## Features

- Bottom Tab Navigation
  - Home
  - My Jobs
  - Messages
  - Profile
- Stack Navigation for Job Details
- Dynamic job details using route parameters
- Reusable components
- Scrollable job and message lists
- Custom icons and UI assets
- Safe-area support for mobile devices

## Technologies

- React Native
- Expo
- Expo Router
- TypeScript
- React Navigation
- JavaScript/TypeScript components

## Reference
 - Icon8 for downloading icons used through out the content
 - Indeed for creating the content based on its design
